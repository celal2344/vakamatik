# Vakamatik 0.1.0 — First-user pilot checklist

Use synthetic or approved training records for this checklist. Do not put patient material in screenshots, issue reports, or email attachments.

## Install and open

- [ ] Copy the complete `Vakamatik-win32-x64` folder to the Windows pilot computer.
- [ ] Start `Vakamatik.exe` without disabling or bypassing Windows security controls.
- [ ] Confirm the About page reports version `0.1.0` and platform `win32`.

## Complete one case

- [ ] Create a case in a writable, backed-up local folder.
- [ ] Assign representative JPEG/PNG records and confirm the selected source files remain unchanged.
- [ ] Enter clinical fields, manual HN/Bolton results, cephalometric values, problem/goal/plan, decision, and notes.
- [ ] Align at least one ordinary image, the slide 22 overlay, and one linked ceph image. Confirm linked slides update and detach remains independent.
- [ ] Move to another tab and slide, close Vakamatik normally, reopen it, and confirm edits and the last workspace position remain.
- [ ] Move a copy of the complete case folder, relink the recent session, and confirm it reopens.
- [ ] With training data only, temporarily remove one managed image, attempt to open the session, then restore it with **Eksik görüntüyü onar** using the exact original file.

## Review and export

- [ ] Review missing-content warnings; confirm export is disabled until the current warnings are acknowledged.
- [ ] Export the PowerPoint and open it in Windows Microsoft PowerPoint without a repair warning.
- [ ] Inspect slide order, optional-slide inclusion, repeated values, image crops/transforms, editable text/tables, and speaker notes.
- [ ] Edit one text field and move one image in PowerPoint, save, close, reopen, and confirm the changes persist.

## Report outcome

- [ ] Record pass/fail, Windows version, PowerPoint version, and Vakamatik version.
- [ ] Report only a synthetic reproduction. Never attach a patient case, patient export, screenshot, or local patient path.

macOS application and PowerPoint checks remain deferred and must not be recorded as passed.
